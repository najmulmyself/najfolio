When a Flutter codebase grows feature by feature, state ends up scattered across widgets and business rules leak into the UI. This post walks through how we split a production app into **presentation**, **domain**, and **data** layers.

## Why BLoC

- Predictable, event-driven state that is easy to test
- A clear boundary between UI and business logic
- Works well with `get_it` for dependency injection

## A minimal use case

```dart
class GetBalance {
  GetBalance(this._repository);
  final WalletRepository _repository;

  Future<Either<Failure, Balance>> call() => _repository.getBalance();
}
```
